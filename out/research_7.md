# Fact-check: "Willy's movement physics" report (JSW1 engine, with JSW2 differences)

I checked each claim against the SkoolKit JSW1 disassembly at https://skoolkid.github.io/jetsetwilly/ . For JSW2 there is no disassembly, so I used the TAS write-ups (8012S for JSW1, 8625S for JSW2), Wikipedia, seasip, the JSWMM forum and the World of Spectrum info file. All numbers below are JSW1 unless marked JSW2.

## B. Important facts the report missed

1. **Auto-pause after inactivity (JSW1).**
   - The timer at 85E0 goes up by one each frame. Any movement or jump input resets it (8F4E, 8F5B, 8F9A).
   - When it wraps to 0 (256 frames with no input), the game drops into the pause loop (8ABB–8AC2).
   - This only happens with the in-game music **off**: 8B3C resets the timer every frame while music plays. The comment says "the game does not automatically pause after a period of inactivity if the in-game music is playing".
   - https://skoolkid.github.io/jetsetwilly/asm/8B07.html , https://skoolkid.github.io/jetsetwilly/asm/85E0.html
2. **Toilet-run behaviour.**
   - Every frame, 8A00–8A0A ORs the animation frame with 1 (comment: "double speed to toilet"), so Willy moves at 4 px per frame.
   - Jump is disabled (8F92–8F94).
   - Bit 0 of the key byte is flipped, which forces him right.
   - https://skoolkid.github.io/jetsetwilly/asm/89AD.html
3. **Asymmetric edge positions.** The frame is kept on a left or right transition:
   - Leaving left (column 0, frame 0) puts Willy at column 30, frame 0, which is pixel 240.
   - Leaving right (column 30, frame 3) puts him at column 0, frame 3, which is pixel 6.
   - To be faithful, reproduce this rather than wrapping pixel-exactly (948A/949E).
4. **Guardian collision is against *any* set pixel in the work buffer at 6000.** That includes room tile graphics, Willy, the rope and guardians drawn earlier. It is not Willy-specific. The 9456 description: "collides with a set bit in the background". JSW rooms are laid out so that guardians avoid tile pixels. A remake should test against Willy's mask, or make sure guardians never overlap tiles. https://skoolkid.github.io/jetsetwilly/asm/9456.html
5. **Arrow kill needs two things:** a set pixel overlap **and** white INK in that cell (91BE 927C–9297).
6. **Item collection means "the item's cell has white INK"** (93EC–93F1). A room whose background INK is white collects its items without Willy touching them (bug "The self-collecting item", Swimming Pool). Avoid white-INK backgrounds, or use explicit overlap. https://skoolkid.github.io/jetsetwilly/asm/93D1.html
7. **Lives:** 85CC starts at 7. A death with 0 remaining means game over (8C37), so there are 8 attempts in total. The in-game music pitch goes up with more lives (8B51–8B58), and redrawing the lives slows each frame.
8. **Bugs that affect edge behaviour**, all on the bugs page, to decide whether to replicate:
   - **"From top to bottom":** jumping off the top of a rope can pass through the top of a room that has no exit up.
   - **"Long distance nasties":** falling out of the bottom of Under the Roof kills Willy if a nasty sits at the top of the room directly above him.
   - **"Stuck in the wall":** entering The Wine Cellar from The Forgotten Abbey, the conveyor pushes Willy into wall tiles.
   - https://skoolkid.github.io/jetsetwilly/reference/bugs.html
9. **Trivia relevant to tile semantics:**
   - "Ropes before Arrows": an arrow drawn before the rope can snap Willy onto the rope.
   - "Slippery slopes" and "Floor ramps" confirm that tile behaviour is decided purely by the attribute byte.
   - https://skoolkid.github.io/jetsetwilly/reference/facts.html
10. **JSW2 timer is an elapsed-time counter.** TAS 8625S: "It holds four digits for the number of hours so will work until 360 million frames have passed". The TAS mentions no time limit, whereas JSW1 ends at 1am. Whether JSW2 has any deadline is **UNCONFIRMED**.
11. **JSW2 lifts and teleporters** (seasip):
    - Each lift uses a guardian slot, so a room with lifts can have at most six guardians.
    - There are 4 teleporters, which "only work if the special-case number for the room is 11 or 22".
    - TAS 8625S: "Each of the four platforms is a teleporter; the top two outgoing and the bottom two incoming."
12. **Blocking sound costs frame time** (timing feel). The jump beep and fall beep each run C = 0x20 half-cycles with delay D (8E16–8E23, 8E85–8E92). The fall beep's D = 16 × airborne, so long falls slow the game. The death sequence plays 8 flash steps, each with its own tone (8C01).
