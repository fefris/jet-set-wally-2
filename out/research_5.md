# JSW2 fact-check: 19 claims checked against primary sources, plus facts the report missed

I checked the JSW1 values against the SkoolKit disassembly pages 8DD3, 8ED4, 8FBC, 87CA, 88FC, 89AD, 898B, 8C01, 9A00 and A400, and against the tables/rooms, reference/facts and reference/bugs pages. No SkoolKit-style disassembly of JSW2 exists. For JSW2 I used John Elliott's partial disassembly (SEA), the DigitalDuck TAS notes (TAS-ANY), JSWCentral, WoS and the WoS in-game screenshot, which I viewed at 4x.

The following were also verified on the way: SHIFT+SPACE quits in JSW1 (8AB8). The bed is a left-to-right conveyor with pattern 0x55 (SK facts). Conveyors animate only if the room has one contiguous conveyor (SEA). The rocket takes off once the room's objects are collected (JDW route). The best-case speed is about 0.04 s per frame, inputs are read once per frame, and turning the music off and having fewer lives both make the game faster (TAS).

## Important facts the report missed

- **Exact jump table (per frame):** Δy is −4,−4,−3,−3,−2,−2,−1,−1,0,0,+1,+1,+2,+2,+3,+3,+4,+4 px (JSW1 8DE3). The TAS gives JSW2 the same 18/20/36 figures.
- **Landing during a jump happens only at cell-aligned heights.** These are jump counter 13 (2 cells above take-off), counter 16 (1 cell above) and after counter 18 (take-off level). So the **highest ledge you can jump onto is 2 cells (16 px)** above your feet (8E2D–8E33). The head still reaches 20 px, so items up to about 5 cells above the floor can be touched.
- **Ceiling bump:** every jump frame checks the top two cells for a wall. On a hit, y snaps to the cell below the wall and the airborne status is set to **2**. The fall counter therefore restarts, and Willy gets a fresh 32-px safe fall from the bump point (8EBC–8ED1).
- **No air control, straight-down falls:** when a fall starts, horizontal movement is cleared (8E6A `RES 1,(85D0)`), so falls are vertical. The jump direction is fixed at take-off. TAS: movement checks are skipped while airborne.
- **Walk-off hover frame:** on the first frame off an edge the status is set to 2 and Willy does not move down (8EB6). The descent starts the next frame.
- **Landing rule (JSW1):** Willy lands only if a cell beneath him is non-background and **neither** cell beneath him is a nasty. If either one is a nasty he keeps falling into it and dies (8E49–8E5F).
- **The airborne status is capped:** it goes 0x10 → 0x0C, so a long fall stays lethal. Sound pitch formulas: jump D=8·(1+|J−8|), fall D=16·status (8E12, 8E80).
- **Room transitions from vertical motion:** a jump that takes y above 0 moves Willy into the room above (8DEF). A floor check below row 15 moves him into the room below (8E44).
- **JSW1 "sticky bed" bug:** after all items are collected, jumping onto the bed (a right conveyor) stops Willy and makes 'P' unresponsive. JSW2's Master Bedroom handler ("if standing on a right-moving conveyor, start him running right") appears to sidestep this. https://skoolkid.github.io/jetsetwilly/reference/bugs.html
- **Lives display (JSW1):** the life figures animate with frames chosen by the in-game music note index at 85E1, so they "dance" in time with the tune (898B). Row 19 in JSW1 uses an ink gradient of 1–7 then 7…1 (9A00 table).
- **Guardian timing (JSW2):** a counter loaded from CG0 is decremented every game-loop pass. At 0 it reloads from CG1 and the guardian reverses. Doubling the step doubles both speed and range (SEA §6).
- **Teleporter records:** the destination byte is the room number **+1**. Teleporters work only in rooms whose special-case ID is 11 or 22 (SEA §8).
- **JSW2 copy protection:** a colour-grid code card check runs on load (TAS). Useful only as flavour.
- **Staircase quirk:** because stairs warp Willy between cells internally, a jump started on a stair can "instantly shoot upwards six pixels" (TAS).
- **Loony Jet Set** loops vertically, meaning the room wraps onto itself (TAS). This is more than "invisible ramps".
- **JSWCentral completion stats:** 100 or fewer rooms need to be visited for a minimum completion. The best times are 0000:42:42 (minimum items) and 0001:08:11 (all items). https://jswcentral.org/jsw2-01_jsw2.html
- **Minor correction to the Central Cavern entry:** WOS-TXT and WOS-128 call it "a playable room, but inaccessible". JDW and the programmers call it unplayable. SEA's code note ("If Willy has won, jump on the spot repeatedly") supports the non-playable reading.
